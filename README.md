# 14S2P-Li-Ion-Battery-Pack-with-Integrated-IPCU_-Project
Mechanical design and ANSYS FEA of a 14s2p Li-ion battery enclosure with integrated APM for 2W, 3W, and MHEV applications. Features a 3-compartment CAD architecture, GD&amp;T, alongside structural (bolt preload), thermal, and modal analysis.
